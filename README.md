# Beyond Fotboll – Futsal Cup

Hemsida för Beyond Fotboll UF:s futsalturnering (10 januari 2027). Statisk sida (en `index.html` + `assets/`) som publiceras med GitHub Pages.

## Anmälan
Formuläret skickas via [FormSubmit](https://formsubmit.co) till **beyondfotboll@gmail.com**. Ingen server behövs.

**Första gången** någon skickar en anmälan får gmail-kontot ett aktiveringsmejl från FormSubmit. Klicka på länken i det mejlet, annars kommer inga anmälningar fram. Skicka gärna en testanmälan direkt efter publicering.

Fält: lagnamn/förening, antal lag, kontaktperson (valfritt), mejl, telefon, övrigt.

## Uppdatera innehåll
Allt innehåll ligger i `index.html`. Plats, priser och avgift finns i sektionen `#info` och i FAQ:n.

## Lokalt
Öppna `index.html` i webbläsaren.
